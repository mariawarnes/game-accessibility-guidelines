Each platform version of a game is scored separately, since accessibility support can differ between them. Choose an access need to re-rank, or filter by platform.

How scoring works

  • Every status comes from a linked source. Nothing is estimated.
  • Met = 1 point. Partial = ½ point. Missing and Unknown = 0 points.
  • Unknown means no source was found. It does not mean the feature is missing.
  • The score is a verified minimum. Games with lots of unknowns may score higher once checked.
  • Coverage shows how much of the checklist has evidence. Under 25% is flagged.
  • Each game has one row per platform. A source only counts for the platform it actually names (e.g. a PS5 review only scores the PS5 row); a source that doesn't name a platform counts for every version of that game. This means one version can score much higher than another simply because it's the one that's been reviewed.
  • Sources were checked on 29 September 2026. Older sources are dated so you can judge them.
